# Currency Converter App

A full-stack currency converter web application built with React and Node.js.

## Overview

Currency Converter is a web application project designed to provide a user-friendly interface for currency conversion.

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- TailwindCSS

### Backend
- Node.js
- Express.js

## Project Structure

```text
Currency_app/
├── client/     # React frontend
└── server/     # Node.js backend
```

## Getting Started

### Prerequisites
- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/sandanila/Currency_app.git
cd Currency_app
```

### 2. Run the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Run the backend

Open a separate terminal:

```bash
cd server
npm install
npm start
```

Make sure the backend configuration and required environment variables are set before running the application.
